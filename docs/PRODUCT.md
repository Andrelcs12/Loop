# Produto

O núcleo pretendido do Loop é:

```text
Task
↓
Faça Agora
↓
Sessão
↓
Resultado
↓
Histórico
```

Implementado: autenticação, usuário de domínio, Setup persistido, Commitment inicial e Task V1 (criar, listar, obter, editar e arquivar).

Milestone atual: validar Task V1 no fluxo manual completo.

Futuro, não implementar antes de validação explícita: TaskExecution, sessão de foco/Pomodoro, motor Faça Agora, IA, comunidade, ranking, hábitos, projetos, assinatura, notificações e calendário externo.
